# phumelela-day-care-website
A modern, responsive website for Phumelela Day Care, designed to provide parents with information about the daycare, services, activities, and contact details.
A modern and responsive website designed for **Phumelela Day Care**.

## 🌐 Live Website

[View Live Website](https://phumelelaa.netlify.app/)

## 📌 About The Project

Phumelela Day Care is a website designed to give parents and guardians an easy way to learn more about the daycare, its programs, activities, and services.

The website focuses on creating a welcoming, professional and user-friendly experience for parents looking for quality childcare.

## ✨ Features

- Responsive design
- Modern homepage
- About Phumelela Day Care section
- Daycare programs and activities
- Image gallery
- Contact information
- Contact form
- Mobile-friendly navigation
- Interactive JavaScript elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## 📱 Responsive Design

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile

## 🎯 Project Goals

The main goal of this project was to create a professional online presence for Phumelela Day Care while making it easy for parents to find important information about the daycare.
